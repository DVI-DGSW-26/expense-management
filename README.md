# 사무실 경비

[Expenses API](https://api.dvi-ind.com/expenses/swagger-ui/index.html)를 사용하는 웹 화면입니다.
경비, 구독(주기 결제 자동 생성), 임차관리비, 첨부파일, 연간 집계, 차변계정을 관리합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성
```

API 서버의 CORS 허용 출처가 `http://localhost:5173` 과 `https://expense-management-zefa.vercel.app` 이라서 개발 서버 포트를 5173 으로 고정했습니다.
다른 주소로 배포하려면 API 서버의 CORS 허용 목록과 로그인 리다이렉트 허용 목록에 그 출처를 추가해야 합니다.

API 주소를 바꾸려면 `.env.local` 에 지정합니다 (`.env.example` 참고).

```
VITE_API_BASE_URL=https://api.dvi-ind.com/expenses
```

## 로그인

1. 로그인 화면의 **DVI 통합 로그인**을 누르면 `/expenses/oauth2/authorization/keycloak?redirect={지금 접속한 출처}` 로 이동합니다.
2. 통합 로그인이 끝나면 API 서버가 `{출처}/auth/callback#token=…&refresh=…` 로 돌려보내고, 앱이 토큰을 저장해 바로 로그인됩니다.
   권한이 없으면 `#error=` 로 사유가 오고 로그인 화면에 표시됩니다.
3. 앱 토큰(30분)이 만료되면 갱신 핸들로 `/auth/refresh` 를 불러 화면 이동 없이 이어서 씁니다.

`redirect` 는 서버 허용 목록(`http://localhost:5173`, `https://expense-management-zefa.vercel.app`) 안의 출처만 받습니다.
목록에 없는 출처면 배포 주소로 돌아갑니다.

`/auth/callback` 같은 경로를 새로고침해도 열리도록 `vercel.json` 에서 모든 경로를 `index.html` 로 보냅니다.

토큰 발급 페이지(`/expenses/login/swagger`)에서 받은 토큰을 붙여넣는 방식도 로그인 화면의 **토큰을 직접 붙여넣기**에 남겨 두었습니다.

## 엑셀로 경비 가져오기

경비 화면의 **엑셀 가져오기**에서 .xlsx 파일을 고르면 미리보기 후 `POST /expense/bulk` 한 번으로 등록합니다.

- 머리글에 `일자 · 거래처 · 품명 · 공급가액 · 세액 · 합계 · 차변계정`(선택: `연도`, `사업자등록번호`)이 있는 시트를 읽습니다. 이름에 '경비'가 들어간 시트를 먼저 찾습니다.
- 일자는 엑셀 날짜, `2026-07-07`, `7/31/26`, 연도 칸과 합친 `07-07`을 읽습니다.
- 차변계정은 이름이 같은 계정을 쓰고, `(판)` 같은 접두어만 다르면 기존 계정에 맞추며, 없으면 새로 만듭니다.
- 같은 일자·거래처·품명·합계의 경비는 미리보기에서 '건너뜀'으로 보여 주고, 서버도 다시 확인해 건너뜁니다.
- 합계는 서버가 공급가액 + 세액으로 계산합니다. 엑셀 합계가 다르면 미리보기에 * 로 표시합니다.

## 임차관리비

- 임대료·관리비는 **고정 금액**(`GET/PUT /lease-cost/fixed`)으로 서버가 매달 자동 등록합니다. 임차관리비 화면의 **고정 금액 변경**에서 금액·적용 시작 월·자동 등록 켜기/끄기를 정합니다.
- 전기료·부가세·전력기금은 청구서를 보고 달마다 입력합니다. 입력하지 않은 값은 `null` 이며 '미입력'으로 표시됩니다. 입력했던 값을 비우고 저장하면 `clear` 로 미입력으로 되돌립니다.
- 부가세 칸 아래의 버튼으로 공급가 계(임대료 + 관리비 + 전기료)의 10%를 넣을 수 있습니다.
- 집계에서 임대료·관리비·전기료·부가세는 지급임차료, 전력기금은 수도광열비로 들어갑니다.
- 임차관리비 화면의 **엑셀 가져오기**로 청구서 엑셀(`날짜 · 청구월 · 임대료 · 관리비 · 전기료 · VAT · 전력기금`)을 가져옵니다. 없는 달은 새로 등록하고, 서버가 자동 등록한 달(`autoCreated`)은 엑셀 값으로 빈 항목을 채우며(PATCH, 임대료·관리비가 다르면 함께), 직접 등록된 달은 건너뜁니다.

## 화면

| 경로 | 내용 | API |
|---|---|---|
| `/expenses` | 경비와 임차관리비를 한 표로(연도·일자(0709)·거래처·품명·금액·차변계정·첨부), 상단에 일반경비(공급가액+세액)·임차관리비·합계, 연·월 또는 기간 조회(`from`·`to` 한 번 호출), PDF 다운로드, 등록/수정/삭제, 첨부파일. 임차관리비는 "임차관리비 n원" 한 줄로 묶이고 누르면 임대료·관리비·전기료·부가세·전력기금으로 펼쳐짐 | `/expense`, `/lease-cost`, `/attachment` |
| `/subscriptions` | 구독 등록/수정(원화·외화), 일시중지·재개, 해지일, 결제 내역(외화는 환율 포함), 결제분 수동 생성 | `/subscription` |
| `/lease` | 월별 전기료 그래프, 임차관리비 연간 12개월 표, 고정 금액 설정, 월별 입력·수정·삭제, 엑셀 가져오기, 첨부파일 | `/lease-cost` |
| `/summary` | 월별 지출 막대 그래프, 월별 표, 차변계정별 합계(임차관리비 포함) | `/summary` |
| `/accounts` | 차변계정 추가·이름/순서 변경·삭제 | `/debit-account` |

```
src/
  api/        client.ts (토큰·요청·자동 갱신), endpoints.ts, types.ts
  auth/       로그인 상태, 로그인 화면
  components/ 공용 UI, 첨부파일, 차변계정 선택
  pages/      화면별 컴포넌트
  styles.css  디자인 토큰과 전체 스타일 (다크 모드 포함)
```
